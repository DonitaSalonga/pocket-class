# project-2

iPhone app (SwiftUI) for a school project: teachers upload presentations and exercises to courses, students open them.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on `DonitaSalonga/project-2`. See `docs/agents/issue-tracker.md`.

Default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

## UI work

Follow `docs/design/ui-direction.md`. When building or reviewing UI, use the `ui-ux-pro-max` skill (SwiftUI guidelines) and Emil Kowalski's `emil-design-eng` skill (plus `animate` for motion).
